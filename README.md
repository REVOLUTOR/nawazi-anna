# Mwaliko wa Harusi – Nawazi & Anna

Digital wedding invitation (single page, no build step).

Live: https://revolutor.github.io/nawazi-anna/

Files:
- `index.html` – the invitation (all images and code inside)
- `preview.jpg` – picture WhatsApp shows when the link is shared (1200×630)
- `icon.jpg` – browser tab / home-screen icon

If you rename the repository, update the address in the `canonical` and `og:` tags at the top of `index.html`.
